# 🌍 Global Debt Analytics & Insights

A data analysis project exploring international debt statistics using real-world data from the World Bank.

## 📌 Project Overview

This project analyzes global debt patterns across countries and identifies key economic insights using SQL and Python.

## 🔍 Key Questions Answered

- What is the total amount of debt owed by all countries?
- Which country has the highest debt?
- What is the average debt across countries?
- Which country has the highest debt in specific indicators?
- What are the most common debt indicators?

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| PostgreSQL | Database & SQL queries |
| Python | Data analysis |
| Pandas | Data manipulation |
| Jupyter Notebook | Analysis environment |

## 📊 Key Insights

- Analyzed debt data across 100+ countries
- Identified top debtor nations and debt distribution patterns
- Discovered trends across different economic indicators
- Generated actionable insights for economic analysis
